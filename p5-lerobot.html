01两条路线

同一份数据、同一套评测协议，唯一变量是观测模态。 观测步数、动作视界、执行步数与扩散步数全部对齐，所以两边的差异可以归因到输入。

DP · 视觉-only

ResNet18 编码单目彩色图，与 6 维关节状态拼接后送入 1D U-Net 条件扩散。训练 20,000 步，开环误差 0.0252。

DP3 · 点云

额外接入 2048 点云，PointNet 逐点编码后与图像特征融合，再把条件注入 DDPM。训练 20,000 步，最佳 loss 0.002695。

选择逻辑：图像路线部署成本低、对相机标定不敏感；点云路线把几何从「隐式学习」变成「显式输入」， 在需要精确空间关系的抓取任务上更有优势，代价是必须有一整套深度采集与标定管线。

02DP3 结构

点云、图像、状态三路编码，融合后驱动条件扩散生成动作序列。

  • PointNet 用 Conv1d 而非 Linear：逐点特征提取不需要 reshape，GPU 并行效率更高。
  • 扩散模型是自研的：条件 DDPM，正弦时间步嵌入 + 1D U-Net 主干，支持 squaredcos_cap_v2 噪声调度与 DDIM 采样。
  • 训练配方是段内遮中：预测被遮住的中间动作，历史窗口与目标窗口双向条件，不依赖跨 episode 结构。

03几何链路

点云不是现成的，是从相机画面一步步算出来的。这部分全部自行实现。

3.1 正运动学

按 SO-101 的 URDF 参数实现六自由度正运动学，把关节角换算成末端在基座系下的位姿：

def forward_kinematics_urdf(joint_rad):
    q = np.array(joint_rad[:5]); T = np.eye(4)
    # 每个关节：origin 变换（URDF 的 xyz/rpy） × 关节自身绕 z 旋转
    T = T @ joint_transform([0.0388353, 0.0, 0.0624], [np.pi, 0.0, -np.pi], q[0])
    T = T @ joint_transform([-0.11257, -0.028, 0.0],  [0.0, 0.0, np.pi/2], q[2])
    ...
    return T

变换顺序为 T_origin @ T_joint，与 URDF 父子链定义一致；另有一份 MDH 参数版本做交叉验证。

3.2 手眼标定

眼在手外（eye-to-hand）标定，五个步骤自行完成：采集关节姿态与画面 → AprilTag36h11 角点检测 → 标定矩阵一致性检查 → 位姿与图像时间对齐 → 求解基座到相机外参 T_base_cam。

3.3 点云重建

深度图过滤无效值后按针孔模型反投影，再用外参变换到基座系，最后裁剪工作空间并体素下采样到固定点数。
