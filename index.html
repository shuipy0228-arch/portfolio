PROJECT 01RAG个人项目

具身智能领域离线证据检索系统

BM25 + 稠密向量 + 知识图谱三路召回，RRF 融合与证据充分性门控

面向具身智能领域的证据检索：在完全离线、不依赖真机与外部 API 的条件下， 对论文、机器人手册、实验记录做可溯源检索作答。核心是让「召回」和「不编造」两件事同时可测量。

  • 三路召回：jieba + 标准 BM25、bge-m3 稠密向量（FAISS）、LLM 抽取三元组构建的知识图谱
  • 加法式路由：基础两路常开，命中英文大写词或重复中文专名时再叠加图谱路，规则可单测
  • 门控拒答：LLM 判证据是否充分，不足直接拒答，无答案题正确拒答率 87.5%
  • 评测流水线：QA 合成 → LLM-judge 核验 → 分层划分，Recall / nDCG / MRR 全量可复算

PROJECT 02具身智能科研项目

长程任务示范数据拼接

语义锚点双侧裁剪 + 段内遮中过渡生成 + 五级观测门控

长程操作任务的完整人工示范采集成本高，本项目用两条短程技能示范自动拼出可用的长程训练数据。 难点不在「接起来」，而在接缝处的动作连续性与观测缺口。

  • 语义锚点：以 D_A 最后一次 release、D_B 第一次 grasp 为不可越界的裁剪边界
  • 过渡生成：段内遮中（in-betweening）训练 1D U-Net，FiLM 调制 + cross-attention 双向条件
  • 观测补齐：SE(3) 半径内检索真实帧 → 运动感知生成 → 模糊兜底，逐帧三级降级
  • 门组预注册：接缝速度/加速度/终点/时长全部先定阈值后看结果，测量缺失即 fail-closed

PROJECT 03全国一等奖源码不公开

双臂二指解魔方机器人

四摄像头六面识别 + 透视校正 + Kociemba 求解 + 时间最优双臂动作寻优

面向魔方自动复原，需要同时解决「六面视觉感知」与「双臂机械动作解算」的协同。 负责上位机全链路：视觉识别、求解调度、机械动作寻优、串口通信与整机联调。

  • 视觉：DirectShow 四路采集，LAB 空间 Canny + 轮廓矩质心 + K-Means(K=6) 颜色聚类
  • 求解：Kociemba 两阶段给出 8 组解，再按同轴组合展开为可执行的机械步骤
  • 寻优：按实测单步耗时累加，在 8 组解 × 2 步 / 2.5 步两套搜索中取总时间最小
  • 执行：自定义串口协议下发，速度曲线预存 Flash，双臂一手持一手拧

面向银发经济的端侧动作识别与跌倒预警

PROJECT 05模仿学习个人项目

基于 LeRobot 的模仿学习策略：DP 与 DP3

视觉策略与点云策略两条路线，共用同一份数据与评测协议

在 SO-101 机械臂上实践两条模仿学习路线：DP（视觉-only）与 DP3（点云）。 两者观测步数、动作视界、执行步数与扩散步数完全对齐，差异只在输入模态，便于直接对照。 从运动学建模到手眼标定、数据采集、训练部署，整条链路自行实现。

  • 运动学：按 SO-101 的 URDF 参数推导六自由度正运动学，由关节角求末端位姿
  • 手眼标定：AprilTag 眼在手外标定，自行求解基座到相机的外参
  • 数据：深度图反投影到基座系生成逐帧点云，53 条示范 / 16,977 帧与视频帧一一对应
  • DP：ResNet18 + 1D U-Net 条件扩散，输入单目图像与 6 维关节状态
  • DP3：PointNet 用 Conv1d 逐点编码，与 ResNet 双流融合后注入条件 DDPM
